## Reporting issues

Open an [issue](https://github.com/playova-app/releases/issues) and pick a template:

- **Bug report** — something is broken or not working as expected
- **Feature request** — you have an idea for Playova

Please include your app version, platform (Android / iOS / macOS) and steps to reproduce.
